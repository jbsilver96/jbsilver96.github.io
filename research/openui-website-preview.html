The Scout

The Scout's first 10 finds

The Scout scans the AI field for new findings, tools, and uncrowded lanes, and files each find as a card with the cheapest honest test that could prove it. Filed Oct 24, 2026.

Learn Where an Agent Run Went Wrong — From Its Successes Alone

A paper (OAT) says a small model trained on just 100 successful agent runs can flag the exact steps that went wrong in a failed run — 200 to 5,000 times faster than asking a big model to review the run.

Scout find — filed, awaiting gate decision

Put a Cage Around an Agent: Anthropic's Sandbox Runtime, on Trial

Anthropic open-sourced its sandbox runtime (srt): it wraps any program and enforces which files it can touch and which network hosts it can reach, at the operating-system level, with no container.

Scout find — triaged by the desk: priority

A Memory Trick That Tracks a Million Steps Without Forgetting

Today's fast sequence models quietly start guessing after about a hundred tracked steps; a Neural Finite-State Machine snaps its memory back to clean values each step and stayed perfect past 1,000,000 steps on the same tasks.

Scout find — filed, awaiting gate decision

One Plug for Every Agent Harness: HarnessRouter

An open-source router puts one API in front of 26 agent harnesses, so the same task can be sent to any of them and switched freely — its pitch: the cheapest harness differs by task, so routing is money.

Scout find — filed, awaiting gate decision

Same Model, Same Tasks, 3× the Bill: What Does the Harness Cost?

A self-published study ran the same AI model on the same coding tasks inside different agent harnesses: the pass rate barely moved, but the bill changed by up to 3×.

Scout find — triaged by the desk: next in line

Stop Asking Humans to Approve Everything: Tiered Gates for Agent Actions

Instead of a human approving every agent action, tiered, evidence-attached approvals cut a 100-action log to 9 real asks plus 3 sampled reviews — each ask carrying the diff, the test run, and the rollback.

Scout find — triaged by the desk: priority

The Induction Leaderboard: an Open-Weights Model Ties a Flagship

On a public benchmark that asks models to guess a hidden rule, the open-weights Kimi K3.1 Pro scored 21% — tied with Claude Opus 5 — while the overall leader sits far ahead at 85%.

Scout find — filed, awaiting gate decision

Let a Program Rewrite the Harness, Not Just the Prompt

Meta-Harness lets an AI read the code, scores, and full run traces of every harness tried so far and write the next harness itself — the harnesses it found beat a state-of-the-art hand-built system by 7.7 points while using 4× fewer context tokens.

Scout find — filed Oct 24, triage pending

A Poisoned Tool Menu Can Hijack an MCP Agent

A tool-menu entry crafted to sound irresistible gets picked by an agent 93.6% of the time — and can then steer the agent, steal information, or run up a token bill 32 times the normal cost.

Scout find — filed Oct 24, triage pending

A Compact Language for Agent-Built Screens: Same UI, Half the Tokens

OpenUI lets a model stream a tiny purpose-built language instead of verbose JSON when it builds a screen on the fly — 4,800 tokens across seven test screens, where two JSON approaches used about 10,000 each.

Scout find — filed Oct 24, triage pending
