Frozen packet wordings (verbatim; identical in R1 and R2)

Fidelity note of record: statements were taken from the problems' registry pages fetched 2026-10-23; for #992, #1105, and #1089 the site returned HTTP 403 during preparation, so those three statements come verbatim from the Aletheia companion file (google-deepmind/superhuman, aletheia/Erdos/Erdos.tex).

  • #333 — "Let A ⊆ ℕ be a set of density zero. Does there exist a B such that A ⊆ B+B and |B ∩ {1,…,N}| = o(N1/2) for all large N?"
  • #591 — "Let α be the infinite ordinal ωω². Is it true that in any red/blue colouring of the edges of Kα there is either a red Kα or a blue K3? In other words, is it true that α → (α, 3)²?" (Prize $250.)
  • #705 — "Let G be a finite unit distance graph in ℝ² (i.e. the vertices are a finite collection of points in ℝ² and there is an edge between two points if and only if the distance between them is 1). Is there some k such that if G has girth ≥ k (i.e. G contains no cycles of length <k) then χ(G) ≤ 3?" — the bolded adjacency condition is the wording at issue between runs (key row, §10.1 of the packet).
  • #992 — "Let x₁<x₂<⋯ be an infinite sequence of integers. Is it true that, for almost all α ∈ [0,1], the discrepancy D(N) = max over intervals I of |#{n ≤ N : {αxn} ∈ I} − |I|N| satisfies D(N) ≪ N1/2(log N)o(1)? Or even D(N) ≪ N1/2(log log N)O(1)?"
  • #1105 — "The anti-Ramsey number AR(n,G) is the maximum possible number of colours in which the edges of Kn can be coloured without creating a rainbow copy of G. Let Ck be the cycle on k vertices. Is it true that AR(n,Ck) = ((k−2)/2 + 1/(k−1))n + O(1)? Let Pk be the path on k vertices and ℓ = ⌊(k−1)/2⌋. If n ≥ k ≥ 5 then is AR(n,Pk) equal to max( C(k−2,2)+1, C(ℓ−1,2) + (ℓ−1)(n−ℓ+1) + ε ) where ε=1 if k is odd and ε=2 otherwise?"
  • #1089 — "Let gd(n) be minimal such that every collection of gd(n) points in ℝd determines at least n many distinct distances. Estimate gd(n). In particular, does limd→∞ gd(n)/dn−1 exist?"
  • #397 — "Are there only finitely many solutions to ∏i C(2mi, mi) = ∏j C(2nj, nj) with the mi, nj distinct?"
  • Heegner case — "RETROSPECTIVE AUDIT QUESTION. It is a classical result that there are exactly nine imaginary quadratic fields of class number one. The complete determination is usually credited to publications from the 1960s. Audit question: was a complete proof of this determination already present in the scholarly record before those 1960s publications? If so, where exactly, when, in what language and venue — and was it accepted at the time?"

9.2 The full solution source and its date

Liam Kruer & Jensen Kohlmeyer, Erdős Problem 14: A Uniform Square-Root Obstruction to Unique Sums (Conjectures; exposition PDF at conjectures.io/papers/erdos14.pdf, read in full during packet preparation).

  • Theorem 1.1. 10.2 #333 — the finite-to-infinite implication evidence

The target asks about an arbitrary infinite density-zero set A. Erdős–Newman 1977 states its results for finite sets — "type (n, N)" estimates (Theorem 2, p. 422) — and says itself, on p. 420, that results for infinite sets "generally follow from these by the familiar process of condensation." The finite-to-infinite step is therefore documented in the source, and the R1 ordinary dossier carries the reduction explicitly: at rapidly increasing scales, typical finite sets force any basis B covering them to satisfy |B ∩ {1,…,Nk}| ≥ ½·Nk1/2 along an unbounded sequence of scales; a set of block minima ≥ ½√N along such a sequence is not o(√N); assembled by condensation, the blocks form a density-zero A for which no suitable B exists — the answer to the target is NO in general. Hence class B (prior theorem + documented routine reduction), not A: the target's statement is not literally in the source.

The three runs show each side of this step: R1 credited it (B/B). R2's multilingual arm opened the same paper in full and declined the step — "does not cover an arbitrary density-zero A" — closing F: the implication failed in practice, in the arm built to be strongest on sources like this. R4's recognition pass credited it again (B/B). Feng et al. (§5.1, Remark 5.1) record the same judgment: the problem's solution "is an immediate consequence" of Erdős–Newman 1977, which "actually predates the posing of this problem."

Standing rules for extension bridge packets

Per dot's specification, an extension bridge packet (a claimed connection between a listed-open problem and prior work beyond this pool) must carry:

  1. A dated open-status listing for the target (what the listing said, and when it said it).
